V4.5 Workflow / Skills Improvement Loop

Recommended first slice: generate evidence-backed recommendations and stop at human-reviewed patch preview.

Architecture Flow
V4.4

Quality Facts

Failure patterns, drilldown, missing evidence, review rework, CI failures.

→
Engine

Recommendations

Group repeated problems into workflow, prompt, skill, or project-rule suggestions.

→
Operator

Review Queue

Accept, reject, or defer. Nothing changes without human approval.

Patch Preview

Reviewable Change

Generate a diff proposal for WORKFLOW.md, central workflow profile, skill instructions, prompt template, or project rules.

↔
Hard Boundary

No Silent Mutation

V4.5 does not auto-commit, auto-edit production rules, or bypass review. V4.6 multi-agent work stays separate.

First Design Section: Product Boundary

V4.5 should extend V4.4 from observation to improvement, but keep the control point human-owned. The unit of value is an ImprovementRecommendation with evidence, scope, confidence, proposed target, and status. Accepted recommendations produce a patch preview; applying or committing the patch is still a separate human-controlled action.
